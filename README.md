# FitLog — Workout & Fitness Planner

FitLog is a modern and responsive workout planning web application built with Next.js. Users can explore different workouts, view detailed workout information, save workouts, and create their own personalized workout plan.

## 🔗 Live Website

https://assignment-006-pied.vercel.app/

## 🛠️ Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- CSS3
- Next.js App Router
- React Context API
- Vercel

## ✨ Key Features

### 1. 🏋️ Workout Library

Users can browse a collection of different workouts from the main workout library. Each workout card provides important information such as workout name, equipment, difficulty, duration, and other useful details.

### 2. 📋 Workout Details

Users can open any workout to view its detailed information, including:

- Workout description
- Required equipment
- Difficulty level
- Duration
- Target muscles
- Step-by-step instructions

### 3. ➕ Add Workouts to My Plan

Users can add workouts to their personal workout plan. The application prevents duplicate workouts from being added to the plan.

### 4. ❤️ Saved Workouts

Users can save workouts and easily access their saved workout collection from the application.

### 5. 📱 Responsive Design

FitLog is designed to work across different screen sizes, including:

- Desktop
- Tablet
- Mobile
- Small mobile devices

The navigation bar, workout cards, plan section, buttons, and other components adapt to different screen sizes.
